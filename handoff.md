# World Cup Match Predictor — Agent Handoff

## Repository

**GitHub:** https://github.com/carami21/WorldCupMatchPredictor
**Branch:** `main`

## Project Overview

An AI-powered FIFA World Cup 2026 match outcome predictor. A Python/Flask backend trains a logistic regression model on 49,000+ historical international football results, and a static frontend provides a polished UI for predictions.

## Architecture

```
WorldCupMatchPredictor/
├── app.py             # Flask API + serves static frontend at /
├── fetch_data.py      # Downloads match dataset from GitHub
├── elo.py             # Custom Elo rating engine (tournament-tiered K-factors)
├── features.py        # Feature engineering (8 features, no data leakage)
├── train.py           # Model training + evaluation (sklearn LogisticRegression)
├── predict.py         # CLI match predictor
├── group_stage.py     # Group stage simulator (Monte Carlo, 10k runs)
├── requirements.txt   # Python deps: flask, flask-cors, pandas, scikit-learn, etc.
└── static/
    ├── index.html     # Single-page app (hero, pitch, results, group sim)
    ├── styles.css     # Dark theme, glassmorphism, responsive
    └── app.js         # Three.js golden globe, scroll animation, API calls
```

## Backend

### Tech Stack
- Python 3, Flask, Flask-CORS
- pandas, scikit-learn, joblib, numpy

### API Endpoints (port 5001)

| Method | Path | Description |
|--------|------|-------------|
| `GET`  | `/` | Serves `static/index.html` |
| `GET`  | `/health` | Health check |
| `GET`  | `/api/teams` | List all valid team names |
| `POST` | `/api/predict` | Predict single match outcome |
| `POST` | `/api/group` | Simulate 4-team group stage |

### Predict Request/Response

```json
// POST /api/predict
// Request:
{ "home": "Brazil", "away": "Argentina", "neutral": true }

// Response:
{
  "home": "Brazil", "away": "Argentina",
  "home_elo": 1931, "away_elo": 2037,
  "home_form": 0.70, "away_form": 1.00,
  "probabilities": { "home_win": 0.194, "draw": 0.245, "away_win": 0.561 },
  "prediction": "away_win",
  "prediction_label": "Argentina win"
}
```

### Group Request/Response

```json
// POST /api/group
// Request:
{ "teams": ["Brazil", "Argentina", "Mexico", "United States"] }

// Response includes: matches[], expected_table[], monte_carlo[]
```

### Model Pipeline
1. `fetch_data.py` — downloads CSV from martj42/international_results
2. `elo.py` — replays all matches to compute Elo ratings (start: 1500, K-factors: 20–60 by tournament tier)
3. `features.py` — builds 8 features per match: elo_diff, home/away form, goals avg, goals conceded avg, is_neutral
4. `train.py` — trains sklearn LogisticRegression with StandardScaler, saves to `models/model.joblib`
5. `app.py` — loads model at startup, serves predictions

### Data Files (git-ignored, generated locally)
- `data/results.csv` — raw match data
- `models/model.joblib` — trained model bundle (pipeline + Elo DataFrame)

## Frontend

### Tech Stack
- Vanilla HTML/CSS/JS (no build step)
- Three.js r128 (CDN) for 3D golden globe
- Google Fonts: Montserrat (headings), Inter (body)

### Key Design Decisions

**Golden Globe (hero section):**
- Three.js `MeshPhysicalMaterial` with `metalness: 0.88`, `roughness: 0.12`, `clearcoat: 1.0`
- Procedural equirectangular texture (2048x1024 canvas): gold gradient base, continent outlines, lat/lon grid
- Bump map makes continents physically raised
- ACES filmic tone mapping for cinematic gold look
- Scroll-driven exit: rolls right/down, shrinks, fades as user scrolls past hero

**Pitch section:**
- Background image generated by Higgsfield AI (hosted on CloudFront CDN):
  `https://d8j0ntlcm91z4.cloudfront.net/user_3ExTZ9Vq14Pkl2Niqqh4XjCKsoZ/hf_20260610_201410_03de2ff6-0d37-4e63-9e54-6aae9885ab85.png`
- Glass-morphism prediction card overlaid at center

**Color scheme:**
- Background: `#0a0e17`
- Primary: `#6a1b4d` (maroon)
- Accent: `#f5c518` (gold)
- Cards: `rgba(15, 20, 35, 0.92)` with backdrop blur
- Text: `#f0f0f0`, muted: `#8a94a6`

### Static Asset Paths
Flask serves static files at `/static/*`. The HTML references:
- `/static/styles.css`
- `/static/app.js`
- Three.js from CDN

### Mobile Responsive
- 640px breakpoint: pitch gets taller padding, card shrinks, inputs stack
- 900px tablet breakpoint
- Standings table wraps in `.standings-table-wrap` for horizontal scroll

## Known Limitations / TODO

- **No authentication** — API is fully open with CORS enabled for all origins
- **No database** — model and Elo ratings are computed from CSV at startup
- **No caching** — predictions are computed fresh on every request
- **Model accuracy** — ~60% on 3-class classification (win/draw/loss), logistic regression baseline
- **Mobile pitch** — card overlays the pitch background, which gets cropped on very small screens; could benefit from a stacked layout
- **No tests** — no unit or integration test suite exists
- **CDN images** — pitch background and any Higgsfield assets are hosted externally; consider downloading and serving locally for production
